# UI Copywriting method

Adapted from the Copywriting pillar of the Growth.Design C.L.E.A.R. framework. Copy answers one question: **why should I care, right now?** Then it says what to do and what will happen next.

## Three mistakes

| Mistake | Symptom | Fix |
|---|---|---|
| **Too long** | A block of three or more lines. People glance, skim, or leave. | Cut until only necessary words remain. Short copy takes many drafts; you do the hard thinking so the reader does not have to. |
| **Too generic** | Words that leave the reader guessing or uninterested. | Name the specific benefit and the specific outcome. |
| **Unnecessary and duplicated** | Extra sentences, or the same fact stated twice. | Remove. Repetition hides what matters and raises the chance of confusion. |

## Four tips

1. **What's in it for me?** Before shipping a headline or CTA, make the benefit obvious in a second or two. Keep rewriting until the reader can see how it helps them.
2. **Reassure.** People hesitate when they are unsure or have unanswered questions. "You can change this later", "No prep needed", "Takes about a minute" unblock them. Reassurance must be concrete, not "don't worry".
3. **Use specific, action words.** Clear verbs and concrete outcomes, so nobody has to guess what a control does.
4. **Talk like a real person.** Write as you would speak to a friend, not as you were taught in school. Read it aloud; if it sounds off, say it again in your own words.

## The Copy Swap Test

Remove all logos and visuals and read the copy aloud. Could a competitor use the same words on their site? If yes, the copy is too vague. Your copy is not unique if someone else can use it.

## Feedforward

An action should announce its consequence before it is taken. A vague verb with an unknown outcome feels risky and gets skipped. Name what will happen, make the next step less scary (review before commit, undo available), and reduce the fear of acting.

## Where copy sits in the wider framework

Copy is the first pillar because it decides what is on the screen at all. Cutting copy is also a layout fix (less content cramming) and an emphasis fix (fewer things competing). If the rewrite leaves the screen visually awkward (a lone input, a faint button), that is expected and is handled by layout and emphasis, not by adding words back.

## Worked example 1: a "tidy up" prompt

A chat app showed a prompt offering to "tidy up" channels the user had not visited, with a button labelled with that vague verb.

Problems: the action is unclear, and there is no feedforward. Does it leave, archive, or delete? Too risky to click.

Rewrite direction: name the benefit (less noise), make the next step safe (review the list first), and reduce the fear of acting.

| Before | After |
|---|---|
| Headline: You have some channels you haven't visited in a while. Tidy up? | Headline: 4 channels have been quiet for months. Want less noise? |
| Button: Tidy up | Button: Review the 4 channels |
| Secondary: Later | Secondary: Keep them |

An equally valid alternative keeps the primary as "Archive 4 quiet channels" with helper text "You can restore them any time". Both name the outcome; they differ in how much confidence the product has earned.

## Worked example 2: an identity-verification screen

Before: a formal, programmatic paragraph explaining that validation is required because the workstation is not registered, with the phone number and the time limit buried in fine print, plus a "Print" link and duplicate branding. Classic "IT designed this".

After, applying cut the noise, talk to a person, be precise:

| Element | Before | After |
|---|---|---|
| Headline | User validation | Enter the code we sent you |
| Body | Multi-line explanation of why validation is required | We texted a 6-digit code to the phone ending in [last 4 digits]. It expires in [N] minutes. |
| CTA | Confirm | Verify code |
| Extras | Print, duplicate logo | removed |

Every removed line was either unnecessary, duplicated, or explaining the mechanism rather than the benefit. The screen will look sparse afterwards; layout and emphasis fix that.

## Quick checklist

- [ ] Benefit visible in one to two seconds
- [ ] Specific verb, concrete outcome
- [ ] Feedforward: what happens next is stated
- [ ] One short reassurance where hesitation is likely
- [ ] No three-line blocks, no duplicates
- [ ] Reads naturally aloud
- [ ] Fails the Copy Swap Test for competitors (they could not reuse it)
